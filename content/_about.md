# 方法与声明

> **本站不构成临床诊疗建议。** 内容供兽医、研究者与行业从业者参考文献使用；临床决策请以原文、现行指南与执业判断为准。

## 收录范围
犬、猫兽医文献。专科：肾病、心血管、内分泌、营养、行为与认知、日本流行病学等。只收录真实可查的文献，每篇附 PubMed / DOI 链接。证据评价只采用公认工具（Oxford CEBM 2011；偏倚风险 RoB 2、ROBINS-I、QUIPS、SYRCLE、AMSTAR 2、AGREE II；报告规范 CONSORT 2010/STROBE-Vet/ARRIVE 2.0/PRISMA 2020/AGREE-RIGHT），详见“证据评价方法”。

## 参与者
**VetLit 的文献提取、翻译与评估由 AI agent 完成：deep extract（提取、翻译）、Vibe Feline（排序、裁定）。**

- **deep extract**：开放获取全文逐篇精读与结构化提取；中英对照翻译（数字与单位逐项核对，原文自相矛盾处加译注）。
- **Vibe Feline**：证据等级（CEBM）与排序；偏倚风险、AMSTAR 2 的第二评估与第三方裁定；许可审核。
- 尚无临床兽医审阅；尚无第二译者审校。

## 标签含义
- **双重独立评估并经第三方裁定**：两位评估者各自独立评定，分歧由第三方裁定。
- **经第二评估者逐条核对**：第一评估结果由第二评估者逐条复核。
- **单人评估/提取**：仅一位评估者完成。
- **译文：VetLit 翻译流程（全文翻译 + 数字与单位逐项校验，原文矛盾处加译注；尚无第二译者审校）**：译文流程说明，由 deep extract 翻译。如有出入，以英文原文为准。

## 数据流程
1. **每日自动检索**：通过 NCBI E-utilities 检索目标期刊（JVIM、JFMS、JAVMA、Vet J、JSAP、Front Vet Sci 等），规则过滤物种 MeSH（Cats / Dogs）与文献类型。新条目标记为 **待处理**，证据评价为 **待评**。
2. **核对**：结构化数据（设计、样本量、一句话结论及工具评定）由 Vibe Feline 核对；开放获取全文由 deep extract 逐篇精读，生成速读页。
3. **核对级别**：每篇标注 **全文已核** 或 **摘要级**。由摘要推断的信息标 **推断**。未能确认的字段写“未核”，不猜测、不编造。

## 速读页结构
页面上方：一句话结论 → 临床意义 → 最多 3 个关键数字 → 中英对照与相关阅读。下方折叠的“证据与方法”：证据评价（CEBM / 偏倚风险 / 报告规范）、研究卡片、全部关键结果、方法学审读、能说明 / 不能说明、原文不一致与许可。

未显示证据确定性的文献，表示尚未评定或不适用，不代表证据可靠。
