# 速读页：Acierno et al., 2018（ACVIM 犬猫系统性高血压共识）

**ACVIM consensus statement: Guidelines for the identification, evaluation, and management of systemic hypertension in dogs and cats**
Acierno MJ, Brown S, Coleman AE, Jepson RE, Papich M, Stepien RL, Syme HM. *J Vet Intern Med* 2018;32(6):1803–1822.
DOI：[10.1111/jvim.15331](https://doi.org/10.1111/jvim.15331)　PMID 30353952　PMCID PMC6271319
**开放获取**：是（CC BY-NC 4.0；全文读自 Europe PMC）
专科：肾病 / 心血管（种子库标为肾病；实为高血压指南，覆盖肾、眼、脑、心等靶器官）　物种：犬、猫
利益冲突：7 位作者均披露厂商关系，6 位为 Boehringer Ingelheim 顾问或接受其资助（Papich 披露的是 Zoetis、Elanco、Merck、Dechra）。

## 1. 一句话结论 + 证据等级
**一句话结论**：按收缩压（SBP）把犬猫分为正常（<140）、高血压前期（140–159）、高血压（160–179）、重度高血压（≥180 mmHg）四级；除非存在靶器官损伤（TOD），诊断需多次测量确认；治疗目标是 SBP <140，至少降到 ≤160；首选药物猫为氨氯地平，犬为 RAAS 抑制剂。

**证据等级：A**（按模板规则：共识指南定为 A）　标签：`专家共识 · 非系统综述 · 无逐条证据分级 · 部分推荐为经验/外推`
- 规则触发情况：指南不适用样本量、排除率、P 值类降级条件；有动物临床推荐，不属于"不适用"。
- **重要提醒**：A 只是文献类型等级，不代表每条推荐都有 A 级证据。原文明确说急症处理"recommendations are anecdotal and extrapolated"，测压设备"no device has met these criteria in conscious dogs or cats"。

## 2. 研究卡片
| 项目 | 内容 |
|---|---|
| 物种 | 犬、猫 |
| 品种 | 不适用（指南指出视觉猎犬院内 SBP 较其他品种高约 10–20 mmHg；猫未见品种效应） |
| 实际分析样本量 | 不适用（叙述性共识；无系统检索与纳入流程描述） |
| 设计 | ACVIM 共识声明（更新 2007 版），专家组 7 人；草案征求 ACVIM 会员意见后投稿；2017 ACVIM Forum 报告 |
| 干预/剂量（要点） | 猫：氨氯地平 0.625 mg/猫/d（SBP <200）或 1.25 mg/猫/d（SBP >200），极少需 2.5 mg/猫/d；替米沙坦为欧洲注册药（降压研究用 2 mg/kg/d）。犬：ACEi（依那普利或贝那普利 0.5–2.0 mg/kg PO q12h）首选；ARB 替米沙坦 1.0 mg/kg q24h 为替代；SBP >200 时 RAAS 抑制剂加 CCB（氨氯地平 0.1–0.5 mg/kg q24h）联用；犬避免 CCB 单药 |
| 主要终点 | 不适用 |
| 随访 | 不适用；建议 IRIS ≥2 期或患相关疾病的动物每 6 个月评估一次血压；≥9 岁犬猫每年筛查 |

## 3. 关键推荐与数字
| 主题 | 推荐 / 数字 |
|---|---|
| 测量规程 | 适应 5–10 分钟；袖带宽为肢体周长的 30%–40%；弃第一次读数，取 5–7 次连续一致读数的均值；袖带距心基部垂直距离 >10 cm 时可按 +0.8 mmHg/cm 校正；设备至少每半年校准 |
| 分级（犬猫通用） | <140 正常（TOD 风险极低）；140–159 高血压前期（低）；160–179 高血压（中）；≥180 重度（高） |
| 确诊时间窗 | 有 TOD：单次测量即可开始治疗；140–179：4–8 周内 >2 次测量；≥180：1–2 周内完成 |
| 治疗目标 | 理想 SBP <140；复查 SBP ≥160 应调整治疗；最低目标 ≤160；SBP <120 并伴虚弱、晕厥或心动过速提示低血压 |
| 犬 CKD 次要目标 | UPC 下降 ≥50%，最好降至 <0.5 |
| 猫氨氯地平效果 | 高血压至重度高血压猫 SBP 平均下降 28–55 mmHg；但长期控压未显示延长生存 |
| 猫替米沙坦 RCT（引用） | 2 mg/kg/d，14 天：SBP 变化 −19 ± 22 vs 安慰剂 −9 ± 17 mmHg（P<0.0001）；28 天达 SBP 降 >20 mmHg 者 54.6% vs 27.6%；排除了 SBP >200 和有眼部/CNS TOD 的猫 |
| ACEi 在猫 | 不推荐作一线降压药（SBP 下降约 10 mmHg） |
| 继发性比例 | 犬猫高血压 ≥80% 为继发性；猫特发性约 13%–20% |
| 急症 | 首小时降 SBP 约 10%，此后数小时再降约 15%；芬诺多泮 CRI 0.1 μg/kg/min 起，每 15 分钟加 0.1，最大 1.6 |
| 筛查 | 不推荐普遍筛查；≥9 岁犬猫可每年筛查 |

## 4. 方法学审读
- **不是系统综述**：没有检索策略、纳入标准，也没有逐条推荐的证据等级（不像 GRADE）。读者无法从文本判断某条推荐是 RCT 支撑还是专家经验。
- **证据强弱不一**：分级阈值基于"TOD 风险"而不是前瞻性结局数据，原文承认"The precise BP at which TOD occurs in dogs and cats is not known"；治疗目标 SBP <140 部分外推自人类数据和一项犬实验研究。
- **测压设备尚无验证**：原文指出没有任何间接测压设备在清醒犬猫中达到验证标准，但所有阈值都依赖这些设备测得的数值，这是整套体系的根本不确定性。
- **蛋白尿目标属于假设**：作者承认降蛋白尿能否改善肾结局"remains unproven"，但仍将其作为治疗目标（"attractive target"）。
- **利益冲突集中**：多数作者与 BI（替米沙坦、贝那普利生产商）有关系；指南对替米沙坦的描述较谨慎（指出其在重度高血压或有 TOD 猫中疗效未证实），未见明显偏向。
- **与本库其他文献交叉**：指南引用 Sent 2015 替米沙坦组肾功能恶化 2/112、尿毒症危象 1/112 作为 ARB 可能加重氮质血症的警示。

## 5. 四阶段深度整理（指南适配版：背景 / 方法 / 结果 / 讨论 → 引言 / 测量与诊断 / 治疗推荐 / 结论）
### Phase 0：分段微分析
**引言（背景）**
- 核心主张：自 2007 年版发布以来，对正常血压和高血压的认识已更新。
- 隐含前提：专家组综合文献即可形成可靠指引。
- 关键细节：2000 年召集专家组，2007 年发表首版。
**测量与诊断（方法）**
- 核心主张：只有标准化测量才可信；情境性高血压不应治疗；确诊需多次测量。
- 隐含前提：标准化规程能大幅减少"白大褂效应"。
- 关键细节：Table 1 规程；四级分类；不推荐普遍筛查。
**治疗推荐（结果）**
- 核心主张：猫首选氨氯地平；犬首选 RAAS 抑制剂；继发性高血压在治疗原发病的同时就开始降压，不必等原发病控制。
- 隐含前提：降压能减少 TOD（人类证据外推）。
- 关键细节：Table 7 剂量表；急症处理的递减降压。
**结论（讨论）**
- 核心主张：知识缺口仍大，需要大型多中心研究和长期结局研究。

### Phase 1：主题
1. **测量标准化是一切的前提**。
2. **以 TOD 风险驱动决策**，而不是单一血压数值。
3. **物种差异化用药**：猫 CCB，犬 RAAS。
4. **证据缺口**：设备验证、生存获益、急症用药。

### Phase 2：论点—论据
| 论点 | 论据 | 隐含前提 | 评估 |
|---|---|---|---|
| 猫首选氨氯地平 | 多项研究：SBP 降 28–55 mmHg | 降压即获益 | 降压效果确立；生存获益未证实 |
| 犬首选 ACEi | 抗蛋白尿作用、CKD 共病率高 | 降蛋白尿有益 | 机制与专家共识，缺乏犬的结局 RCT |
| 治疗目标 SBP <140 | 人类数据、犬实验研究 | 可外推 | 弱至中等 |
| 犬避免 CCB 单药 | 入球小动脉扩张的机制推理 | 机制可转化为临床危害 | 机制推理 |

### Phase 3：自检
- 所有剂量和阈值都摘自原文 Table 1/6/7 和正文；分级数字在 Figure 1 正文与 Table 6 中一致。
- Table 2 中 Anderson 1968 的犬 SBP "144 ± 156" 疑为原表排印错误，本页未引用。

## 6. 能说 / 不能说
**能说**
- ACVIM 推荐的犬猫高血压四级分类：<140 / 140–159 / 160–179 / ≥180 mmHg。
- 猫一线降压药为氨氯地平，犬一般首选 ACEi 或 ARB，犬避免 CCB 单药。
- 除非有 TOD，诊断需要多次测量确认。
**不能说**
- 不能说降压治疗已被证实能延长犬猫生存（原文明确说氨氯地平未显示延长生存）。
- 不能说这些阈值来自前瞻性结局研究。
- 不能说任何市售间接测压设备在清醒犬猫中已通过验证。
- 不能把急症处理方案当作循证推荐（原文自述为经验和外推）。

## 7. 临床可用性
**改变诊疗**（适用：所有需要评估血压的犬猫，尤其 CKD、甲亢、肾上腺皮质功能亢进、≥9 岁的动物）。这是目前的标准操作参考，但具体数字推荐的证据强度需要逐条看。
